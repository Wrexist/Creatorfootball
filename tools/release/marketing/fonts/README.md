# Inter (vendored)

`inter-latin.woff2` is the Inter variable font, latin subset, from Google Fonts
(v20). `inter.css` is the same file inlined as a base64 `@font-face` so the
renderer never depends on the network — a font that fails to load mid-render
silently changes every headline's size and line breaks.

Inter is licensed under the **SIL Open Font License 1.1**, which permits
commercial use and embedding, including in App Store marketing images.
